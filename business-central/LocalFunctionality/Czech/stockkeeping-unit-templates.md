# Stock keeping unit templates in the Czech version

Set up templates that are used as part of the stockkeeping unit (SKU) creation process.
You define templates for a combination of item category and location, and each template can link to a configuration template that sets basic SKU parameters, such as replenishment system and reordering policy.
When you create a new stockkeeping unit through the **Create Stockkeeping Unit** report, the settings in the matching template are automatically copied to the new SKU card.
