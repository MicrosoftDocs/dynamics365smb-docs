# Vendor - Summary Aging (report)

The **Vendor - Summary Aging** report is a legacy report for aged accounts payable. Report 305 is marked obsolete from version 28.0 and is planned for removal. Its caption is **Vendor - Summary Aging (Obsolete)** in versions where it remains available. We recommend **Aged Accounts Payable (Excel)** instead. Learn more in [Aged Accounts Payable Excel](report-4403.md).

Set a **Starting Date** and **Period Length** to group outstanding amounts by due date. The report shows amounts before the starting date, in three periods of the specified length, and after those periods. Choose **Show Amounts in LCY** to use local currency instead of the vendor entry currency.

## Try the report

Try the report here: [Vendor - Summary Aging](https://businesscentral.dynamics.com?report=305)
