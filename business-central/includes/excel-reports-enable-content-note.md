> [!NOTE]
> This report does the calculations when you view it in Excel for the web, or when you download and open it. If a banner displays text about external data connections, you might need to select the **Enable content** button to load data. Enable content only if you trust the file. The report doesn't connect to any external data sources. Some layouts use Power Query to prepare the analysis worksheets. Depending on your organization's security settings, you might also need to right-click a PivotTable cell in Excel for Windows and select **Refresh** to update data in the report.
