# Output Item Label (report)

The **Output Item Label** report generates labels for items posted as output from a production order. The labels show the item number, description, and base unit of measure. They encode the selected serial, lot, or package number as a linear barcode and a QR code.

You can filter the report by **Order No.** and **Item No.** to limit the labels to a production order or item. Select an **Item Tracking Type** to choose whether the label uses a serial, lot, or package number.

## Use cases

[!INCLUDE [report-99000769-scenario](../includes/report-99000769-scenario-include.md)]

Production and shop floor operators can use the report to:

* Print labels after posting output for a production order.
* Print labels only for items produced on a specific production order.
* Select the tracking type so that the correct number is encoded.

Warehouse and inventory staff can use the report to:

* Attach labels to output items for scanning during put-away or transfer.
* Scan the QR code to find lot or serial information during inventory counts.
* Reprint labels for a specific item without reprinting the entire output batch.
