# Cost Acctg. Statement/Budget (report)

The **Cost Acctg. Statement/Budget** report compares actual net changes and budget amounts by cost type. It shows actual costs in debit and credit columns, the budget amount, and actual costs as a percentage of budget. The percentage is zero when the budget amount is zero.

Set the **Date Filter** and **Budget Filter** for the comparison. You can also filter by cost center or cost object. Choose **Suppress lines without amount** to omit rows where both actual and budget amounts are zero.

## Use cases

[!INCLUDE [report-1133-scenario](../includes/report-1133-scenario-include.md)]

> [!TIP]
> Here are some tips on how to use the report:
>
> * Use the report during budgeting cycles to compare actual versus planned costs.
> * Filter by cost center to compare actual costs with budget and identify overspending or underspending.
> * Use the comparison as an input when adjusting future budgets.
> * Apply cost center or cost object filters for a more focused comparison.
> * Use the report to support internal reviews and financial planning discussions.

Controllers can use the report to:

* Monitor cost center performance.
* Support budget planning and variance analysis.

Finance teams can use the report to:

* Review and validate actual spending against budget expectations.
* Identify trends and adjust financial strategies accordingly.

Auditors might reference the report to:

* Verify budget compliance.
* Assess the accuracy of cost allocations.
