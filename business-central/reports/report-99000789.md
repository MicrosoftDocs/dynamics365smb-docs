# Subcontractor - Dispatch list (report)

The **Subcontractor - Dispatch List** report shows, for each subcontractor vendor and their associated work center, the released production order routing lines that are assigned to that work center, together with the remaining quantity, unit of measure, and any related purchase order details. For each routing line it also lists the production order components that you must ship to the subcontractor before the operation can be performed. The report takes routing links between operations into account so it includes only the components you need for that step.

You can filter the report by vendor number to limit the list to one or more subcontractors, by work center number to focus on specific outsourced operations, and by production order number, starting date, and ending date on the production order routing lines to narrow the results to a particular order or time period.

## Use cases

[!INCLUDE [report-99000789-scenario](../includes/report-99000789-scenario-include.md)]

Production planners can use the report to:

* Identify which components you must pick and ship to a subcontractor before an outsourced operation can start.
* Filter by starting and ending date to prepare dispatch lists for operations scheduled in an upcoming period.
* Check the remaining quantity and unit of measure on each routing line to confirm shipment amounts.

Purchasing agents can use the report to:
* Review outstanding quantities on purchase orders linked to subcontracted operations to confirm what you already ordered.
* Cross-check purchase order numbers against production orders to verify that subcontracting purchase orders are in place before dispatch.
* Filter by vendor number to prepare a dispatch list for a specific subcontractor before a delivery run.
Shop floor coordinators can use the report to:

* Confirm which work centers are tied to which subcontractor vendors before releasing routing lines for outsourcing.
* Verify that the report includes only the components linked through the correct routing link code, avoiding shipment of unrelated materials.
* Use the report as a packing checklist when preparing shipments for multiple production orders at once.
