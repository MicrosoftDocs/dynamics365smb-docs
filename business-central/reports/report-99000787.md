# Routing Sheet (report)

The **Routing Sheet** report shows the operations to do to build an item.

View the work center or machine center and a description of each operation. Select **Personnel**, **Tools**, **Comment**, or **Quality Measures** to include those details. Use **Production Quantity** to specify the quantity for calculating the total routing time.

View basic information for routings, such as:

- Send ahead quantity
- Scrap factor percentage
- Set up time
- Run time
- Wait time
