# G/L Register (report)

The **G/L Register** report groups posted general ledger (G/L) entries by register number. It shows posting dates, document references, accounts, descriptions, posting groups, VAT amounts, and entry amounts. It doesn't identify the user who posted each entry.

Use the register **No.** filter to select posting batches. Turn on **Show details** to include matching posted sales and purchase invoice or credit memo lines for G/L accounts.

## Use cases

[!INCLUDE [report-3-scenario](../includes/report-3-scenario-include.md)]

Controllers and finance teams can use the report to:

* Audit financial transactions by tracing document references and posting dates.
* Review the accounts and amounts posted in a register.
* Cross-reference G/L entries with register batches for reconciliation and compliance.

Auditors can use the report to:

* Verify the accuracy and completeness of posted G/L transactions.
* Identify anomalies or irregularities in posting behavior.
* Support audit trails and documentation for financial reviews.
