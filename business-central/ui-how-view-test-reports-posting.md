# View a test report before you post

When you're ready to post a document, such as an order, invoice, or credit memo, use a test report to identify errors or missing information that might block posting.

> [!NOTE]  
> The following procedure is about testing before you post a purchase document. The feature works in the same way for sales documents.

## Print a test report before you post a purchase invoice

1. [!INCLUDE[open-search](includes/open-search.md)], enter **Purchase Invoices**, and then select the related link.
2. Open the purchase invoice that you want to test.
3. Choose the **Test Report** action.  
4. On the report request page, choose **Print**.

The report checks the purchase invoice and displays any errors or warnings that it finds. Review the reported issues and correct any that prevent posting. The report doesn't perform all posting checks, so a report without warnings doesn't guarantee that posting will succeed.
