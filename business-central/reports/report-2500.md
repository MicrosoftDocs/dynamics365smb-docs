# Day Book VAT Entry (report)

The **Day Book VAT Entry** report displays posted VAT entries by **VAT Reporting Date** and posting type, with entries sorted by document number within each date and type. Use it to review tax postings across sales and purchase documents.

Set a **VAT Reporting Date** range of no more than one year. You can also filter by **Type** and choose **Show Amounts in Add. Reporting Currency**. The report includes deductible and nondeductible VAT amounts.

## Use cases

[!INCLUDE [report-2500-scenario](../includes/report-2500-scenario-include.md)]

> [!TIP]
> Here are some tips on how to use the report:
>
> * Run the report to examine VAT entries grouped by VAT reporting date and posting type.
> * Use it during audits to validate tax postings across documents.
> * Use it for reconciliation tasks by comparing VAT entries over time.
> * Use the VAT reporting date and posting type filters for focused analysis.

Accountants can use the report to:

* Verify VAT postings.
* Support tax reconciliation and compliance reviews.

Controllers can use the report to:

* Monitor VAT activity across periods.
* Ensure accurate tax reporting.

Auditors might reference the report to:

* Verify the completeness and accuracy of VAT entries.
* Support financial and regulatory audits.
