# Resource Statistics (report)

The **Resource Statistics** report shows usage and sales prices from resource ledger entries in local currency. It isn't limited to project transactions.

It also shows the percentage invoiced for each resource and a total for all reported resources.

The percentage is sales price divided by usage price, multiplied by 100. If usage price is zero, the report shows 100 percent. Use **Date Filter** to limit entries by posting date.
