# Resource Utilization (report)

The **Resource Utilization** report compares capacity entries with posted resource usage in each resource's base unit of measure. It shows the remaining balance as capacity minus usage.

Use **Date Filter** to limit capacity by date and usage ledger entries by posting date. The report isn't a forecast of planned project assignments and isn't limited to project transactions.
