# Demand Forecast (Obsolete) (report)

The **Demand Forecast (Obsolete)** report shows the quantities and dates that planning worksheets use, and considers the sales type, component demand, or both.

> [!NOTE]
> This report was marked obsolete in version 27.0 and is planned for removal.

The report displays information such as:

- Item number
- Description
- Location code
- Date
- Quantity
- Type
