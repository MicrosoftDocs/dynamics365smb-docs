# Default business posting group in manufacturing in the Czech version

You can set a default **Gen. Bus. Posting Group** for manufacturing orders so that new orders get a posting group without you having to select one manually every time.

> [!NOTE]
> This setting was originally added as Czech-specific functionality. It's now a standard field on the manufacturing setup, so it applies regardless of your country or region.
